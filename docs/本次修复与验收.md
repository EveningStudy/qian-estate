# 微信预览修复与实用化调整

## 已完成

- 修复详情、个人中心、工作台条件表达式中的 HTML 实体错误，改用原生逻辑运算符。
- 新增微信官方模板与样式编译检查：`npm run test:wxml`。缺少编译器时明确失败，不用静态检查冒充官方编译。
- 原生首页去除宣传文案，前置卖房、委托、查房与工作台；统一小标题、矩形按钮、输入框及紧凑列表。
- 未登录首页提供直接登录入口；演示隐私说明不调用依赖真实应用权限的接口。
- 修复保存后新增照片无法再次保存；未确认业务写入在当前页面会话中复用幂等键。
- 新增真实页面模块到真实本地服务的委托、受理、消息、资料、退出集成测试，使用隔离数据库。
- 重建保留开发者工具中的应用编号、额外工程设置及独立私有设置。
- 网页端取消宣传大标题、展示侧栏和装饰标签，统一无衬线字体和更清楚的表单字号。

## 查看

保持本地服务运行，在已导入的微信工程顶部点击“编译”。不需要重新导入、不需要重装。

模拟器“我的”→勾选说明→进入演示账号→回到首页。业主工程为 `dist/mini-owner`，经纪人工程为 `dist/mini-agent`。
