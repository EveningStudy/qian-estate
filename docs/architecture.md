# 架构与角色功能

## 模块

| 路径                              | 职责                                                                |
| --------------------------------- | ------------------------------------------------------------------- |
| `web/`                            | 浏览器业务界面与管理后台                                            |
| `mini/shared/`、`mini/roles/`     | 双小程序共享实现和构建角色资料                                      |
| `server/src/app.ts`               | 会话鉴权、业务权限与状态、文本安全、图片存储选择和访问              |
| `auth.ts`、`wechat.ts`            | 微信登录/手机号、独立身份、申请审核、管理员配对、订阅与文本安全适配 |
| `service-routes.ts`               | 集成状态、地图、短信、订阅、人工房源核验                            |
| `integrations.ts`                 | 地图、短信及支付密码学工具；支付业务路由未完成                      |
| `object-storage.ts`、`uploads.ts` | 私有 S3 或本地图片、结构校验和随机对象键                            |
| `db.ts`、`validation.ts`          | SQLite 事务、输入和受保护字段                                       |
| `deploy/`                         | 镜像、环境注入、HTTPS 代理与配置测试                                |
| `scripts/`                        | 小程序构建、备份、角色授权、生产检查、交接打包                      |

浏览器和小程序访问接口；接口校验身份、对象归属与业务状态，再写数据库或调用服务。生产上传选择 S3 时记录对象键，读取仍经应用访问检查后获取短期链接。集成状态位于 `/api/integrations/status`，旧 `/api/providers` 仅重定向。

## 身份和角色

新用户始终是 `owner`。两端按 `AppID + openid` 隔离，不合并；经纪人由申请审核升级并进入目录，跨端通过目录协作。初始管理员由服务器角色命令授权，浏览器管理员使用小程序一次性配对。

| 功能         | 业主                 | 经纪人               | 管理员                       |
| ------------ | -------------------- | -------------------- | ---------------------------- |
| 房源与委托   | 提交自己的资料和委托 | 处理分配的委托       | 审核状态与发布               |
| 预约         | 创建、取消自己的预约 | 处理关联预约         | 管理状态                     |
| 联卖与客户   | 不具备经纪人专属操作 | 关联联卖及自己的客户 | 按管理权限处理               |
| 收藏与私信   | 自己的收藏、参与会话 | 同左                 | 不可读取无关私信             |
| 人工房源核验 | 提供材料和授权       | 协助材料             | 登记核验、确认授权、审核发布 |
| 通知订阅     | 主动授权接收         | 主动授权接收         | 受控发送既有通知             |
| 门锁         | 关联申请             | 受托申请             | 仅审批，不操作硬件           |

生产发布要求已有人工核验及授权确认，内容提交另需微信文本安全。修改核验结果不能被当作已自动下架，应由管理员执行相应状态变化。

生产跳过演示种子并拒绝已有演示库；默认经纪人必须真实启用。SQLite 记录身份、会话、幂等、审计、短信挑战、订阅发送和人工核验，备份恢复必须覆盖新表及外部对象。权限矩阵是代码说明，不代表真实环境完成验收。
