# 发布检查清单

- [ ] 对照最新 [.env.example](../.env.example) 与部署模板填写真实配置，可选服务不用时整组省略。
- [ ] 双端微信凭据、HTTPS 地址、来源、运营者名称、支持邮箱和隐私版本正确。
- [ ] `WECHAT_CONTENT_CHECK=true`，实际内容安全权限和错误处理通过。
- [ ] 新生产数据卷不含演示身份；真实经纪人已审批，默认经纪人编号有效。
- [ ] 首个管理员受控授权，重新小程序登录并完成浏览器配对。
- [ ] 房源核验材料、机构登记、业主授权有依据；核验记录通过后才允许生产发布。
- [ ] 地图、短信、订阅消息完成真实受控测试，失败不伪造成功，未知结果不自动重发。
- [ ] 图片私有存储、访问授权、S3 条件写入和预签名链接验证通过。
- [ ] 支付订单、回调、入账、退款和对账仍未完成时不开放收款。
- [ ] 本地测试状态及数量清晰，无零测试假通过或待完成计入通过。
- [ ] Docker 构建、HTTPS、域名、代理、持久化及重启验收完成，不以配置测试代替。
- [ ] 数据库、本地图片/S3 对象共同备份并恢复演练，保留回滚点，不删卷。
- [ ] 交接 ZIP 排除秘密与数据，检查源码和资源无夹带；保存校验值。
- [ ] 业务、运维、安全与隐私负责人确认遗留风险、值班、故障与回滚职责。

操作步骤见[生产交接](production-handover.md)及[部署说明](../deploy/README.md)。发布、授权和真实业务操作需单独批准。
