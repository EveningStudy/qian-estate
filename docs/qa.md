```powershell

```

后端真实认证模拟测试由主后端负责人维护，浏览器套件位于 `tests/`。浏览器需运行本地服务，配置不自动启动服务器，默认 `PLAYWRIGHT_BASE_URL=http://127.0.0.1:4311`。截图和跟踪输出到系统临时目录，不记录秘密。

## 发布前必须补齐

- 双端微信登录、手机号、隐私版本一致、拒绝授权、过期与退出。
- 新用户均为业主、AppID 隔离、经纪人审批、默认经纪人有效、管理员配对过期/重用拒绝。
- 生产拒绝演示库；内容安全、人工核验与未授权发布阻断。
- 地图真实查询；短信冷却、五次尝试、过期、未知结果；订阅用户授权及单次发送。
- 本地及 S3 上传、访问权限、未知上传核对、数据库和图片共同恢复。
- 实际 Docker 部署、证书、代理、重启持久化及回滚。

报告保留版本、时间、完整命令、通过/失败/待完成/跳过数量、脱敏证据和责任人。支付工具测试不能作为收款业务验收。
