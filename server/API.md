# 服务端接口说明

基础地址为部署后的 HTTPS 源站，以下路径均以 `/api` 开始。开发地址为 `http://127.0.0.1:4310`。字段和路径保留机器标识，解释使用中文。生产默认关闭演示登录。

## 登录与身份

| 方法和路径                | 输入                        | 返回和限制                                                                                                  |
| ------------------------- | --------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `POST /auth/wechat/login` | `code, app, privacyVersion` | 微信临时凭证、应用类型 `owner/agent`、当前隐私版本；返回 `token,user`。新用户始终为普通业主，不能提交角色。 |
| `POST /auth/wechat/phone` | `code`                      | 微信手机号按钮返回的动态凭证；必须持有真实微信会话，返回脱敏用户与绑定结果。                                |
| `GET /auth/me`            | 无                          | 当前用户信息，手机号脱敏。                                                                                  |
| `POST /auth/logout`       | 空对象                      | 撤销当前会话，不自动重新登录。                                                                              |
| `POST /auth/demo`         | `role`                      | 仅本地开发显式演示使用，生产拒绝。                                                                          |
| `POST /admin/pairing`     | 空对象                      | 已授权小程序管理员生成八位配对码，六十秒有效。                                                              |
| `POST /auth/admin/pair`   | `code`                      | 管理浏览器消耗配对码换取会话；不可重复使用。                                                                |

私有接口使用 `Authorization: Bearer <token>`。会话有效期为十二小时，令牌只保存摘要。两端按各自应用编号与微信用户标识隔离，不依据客户端角色、手机号或联合标识自动合并账号。管理员首次授权由服务器维护者运行角色授权命令完成，没有默认管理员密码。

## 统一数据与错误

- `GET /bootstrap` 返回当前权限下的用户、房源、经纪人、交易记录、问答、收藏、预约、委托、联卖、客户、消息、反馈、门锁申请、通知和审计数组。
- `GET /properties/:id` 直接返回单条房源；无权访问返回找不到，不泄漏隐藏房源。
- 创建成功直接返回新记录，状态码为 201；更新成功直接返回更新记录，状态码为 200。
- 记录一般含 `id,createdAt,updatedAt,status`。时间采用带时区的标准时间字符串；价格单位为万元，面积单位为平方米。
- 错误格式为 `{error:{code,message}}`，`message` 为中文；常见状态为 400 参数错误、401 未登录、403 无权限、404 不存在、409 状态冲突、413 内容过大、429 限频、502 上游失败、503 未配置。
- 业务创建、状态修改、资料修改和收藏支持 `Idempotency-Key`。网络失败后只对相同接口、正文和业务意图复用原键，不得换键盲目重发。

## 业务创建

使用 `POST /:collection`。客户端不能提交编号、归属用户、角色、审核状态、权限或门锁开关；服务器校验角色、归属和状态。以下为集合名及正文。

| 集合                    | 必填字段                                                 | 说明                                                                     |
| ----------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------ |
| `properties` 房源       | `title,community,city,district,address,price,area,rooms` | 业主创建，初始待审；可填装修、朝向、楼层、图片、产权、税费、占用情况等。 |
| `commissions` 委托      | `propertyId` 或 `community,area,price`                   | 仅业主；已有房源必须属于本人。可填联系人、电话、备注及经纪人编号。       |
| `appointments` 预约     | `propertyId,scheduledAt`                                 | 仅业主预约已发布房源，时间必须在未来。                                   |
| `collaborations` 联卖   | `propertyId`                                             | 仅经纪人申请其他经纪人的已发布房源；收件人由服务器确定。                 |
| `clients` 客户          | `name`                                                   | 经纪人管理自己的客户，可填电话、预算、需求和备注。                       |
| `messages` 消息         | `recipientId,content`                                    | 仅参与者可读；经纪人联系业主须有业务关联，管理员不能旁观私人会话。       |
| `feedback` 反馈         | `content`                                                | 可填分类和联系方式。                                                     |
| `questions` 提问        | `question`                                               | 可关联房源，管理员答复后公开问答内容，不公开提交者身份。                 |
| `lockRequests` 门锁申请 | `propertyId,reason`                                      | 仅业主或负责经纪人；审核绝不触发设备开锁。                               |

生产内容提交调用微信文本安全检查。房源与委托需要一个有效经纪人，可显式传 `agentId` 或配置 `DEFAULT_AGENT_ID`。未配置、经纪人不存在时不能假装委托成功。

## 状态更新

`PATCH /:collection/:id` 只接受 `{status,note?,answer?}`。以下状态值为机器标识，界面应使用中文标签。

| 业务       | 状态与操作                                                                                         |
| ---------- | -------------------------------------------------------------------------------------------------- |
| 房源       | 待审 `pending` → 发布 `published` 或拒绝 `rejected`；发布后可撤回审核或标为已售 `sold`。           |
| 委托、联卖 | 待审 → 受理 `accepted`／拒绝；受理后完成 `completed`／取消 `cancelled`。申请人只能取消自己的请求。 |
| 预约       | 待审 → 确认 `confirmed`／拒绝；确认后完成／取消，预约人只能取消。                                  |
| 客户       | 跟进中 `active` → 已联系 `contacted` → 已转化 `converted`；支持归档 `archived`。                   |
| 消息、通知 | 收件人标记已读 `read`，其他人无权代读。                                                            |
| 反馈、问答 | 管理员处理反馈，答复问答时必须填写 `answer`。                                                      |
| 门锁申请   | 管理员或符合条件的业主可批准 `approved`／拒绝／撤销 `revoked`，设备控制始终关闭。                  |

## 房源编辑、核验与图片

- `PUT /properties/:id`：业主编辑自己的房源、管理员编辑可见房源。只接受内容字段。生产编辑会撤销原核验并把已发布房源退回待审。
- `PUT /property-checks/:id`：管理员填写 `{verified,authorizationConfirmed,code,agencyRegistration,note}`，登记人工核验。`GET` 同路径读取。生产发布必须已完成真实性与业主授权核对；这不是自动连接住建平台。
- `POST /uploads`：必须登录，直接提交图片字节，类型为 `image/png` 或 `image/jpeg`，最大五兆字节；不接受任意文件名和任意格式。验证图片结构与像素尺寸。
- 上传按配置保存到本地持久卷或私有对象存储。返回 `url` 用于保存，`previewUrl` 用于短期预览。未发布图片访问需要签名链接；已发布房源照片可以公开访问。
- 房源图片只允许本人上传或管理员处理的已登记图片。生产禁止内置演示素材。图片移出房源不会立即删除文件，清理须有保留期及引用核对。
- 对象存储上传超时会保留待核对登记，不自动重传；对象备份与版本恢复由存储提供方另外管理。

## 入驻、资料与数据请求

- `GET/POST /agent-applications`：查看／提交入驻申请；正文 `name,company,licenseNumber,city,phone`，手机号必须与微信绑定一致。
- `PATCH /agent-applications/:id`：管理员提交 `{status:'approved'|'rejected',note}`，批准后授予经纪人权限。
- `PUT /profile`：修改自己的 `name,city,bio,avatar`；生产不能手工修改手机号或角色。
- `POST /favorites/:propertyId`：收藏或取消收藏，返回最新结果。
- `GET /account/export`：导出当前用户可提供的个人数据；不是全库导出。
- `POST /account/deletion-request`：正文 `{confirm:true}`，登记注销请求，尚未删除账户。管理员通过 `GET /account/requests` 查看待办，核对未结业务和依法留存事项后另行处理。
- `GET /legal`：当前运营者、联系方式、隐私版本、协议链接与备案号配置。

## 外部服务

| 接口                              | 用途与限制                                                                                        |
| --------------------------------- | ------------------------------------------------------------------------------------------------- |
| `GET /integrations/status`        | 区分已实现、已配置和真实联调；不返回密钥。旧 `/providers` 重定向到此处。                          |
| `GET /map/search?keyword=&city=`  | 登录后搜索地址，使用腾讯地图服务端密钥。                                                          |
| `GET /map/geocode?address=&city=` | 登录后解析地址坐标。                                                                              |
| `POST /sms/challenge`             | `{consent:true}`；只发送到本人微信已绑定号码，五分钟限一次，超时不自动重发。                      |
| `POST /sms/verify`                | `{code}`；验证码五分钟有效、最多五次尝试、不可重复使用。                                          |
| `GET /subscriptions/template`     | 返回已配置的模板编号。                                                                            |
| `POST /subscriptions/grant`       | 小程序主动接受微信订阅后提交 `{templateId,accepted:true}`；服务器记录不等于微信授予最终发送权限。 |
| `POST /notifications/:id/deliver` | 管理员发送已有站内通知，不接受任意收件人和消息正文；结果不确定不重发。当前只支持单标题字段模板。  |
| `POST /valuation`                 | 开发环境固定演示估值；生产未接入真实估价时明确拒绝。                                              |

微信支付仅有签名、应答验签及通知解密工具，没有订单、收款、回调入账、退款和对账路由。身份证人脸核验、地方房源自动核验、真实全景与门锁控制尚未接入，不能仅填配置就声称全部可用。

## 部署与验证

数据库使用 SQLite 持久卷，定位为单实例起步部署；高并发、多实例需要另行迁移与容量评估。生产不注入演示账号，并拒绝误用含演示管理员的数据目录。运行 `npm test`、`npm run test:deploy` 和 `npm run check:production` 检查本地代码与配置；真实微信权限、额度、备案和供应商服务仍须部署方联调。
