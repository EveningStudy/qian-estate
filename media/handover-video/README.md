# 栖岸小程序展示视频工程

使用 Remotion 制作页面展示视频。交接版使用微信模拟器截图与中文说明，不是真机操作录像，也不能作为生产验收证明。画面中的业务数据为演示数据。

## 本地预览

在本目录执行：

```powershell
npm ci
npm run dev
```

视频工程保留在 `media/`，成品输出到项目根目录的 `media/outputs/`，临时素材和日志放在 `work/`。依赖及视频成品不进入源码仓库。

第三方依赖的使用与授权条件请参阅 [Remotion 许可说明](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md)。
